# 床垫选品小程序 — 设计任务书（Design Brief）

> 交付方：Designer（Figma 出稿）
> 消费方：用户确认 → CC（Claude Code）按稿实现 → Hermes（pm）对照验收
> 版本：V1.1 / 2026-11-04，需求源：docs/product-specs/PRD-v1.1.md

## 0. 画板与全局规格（先做，作为 Design System 页）
- 基准 375 x 812（iPhone），出图 2x
- 设计 token 一份（命名/取值齐全）：色板（primary/成功/警告/危险/中性灰阶 8 级）、字号梯度（大标题 24/标题 20/正文 16/辅助 13/标签 11）、间距梯度（4/8/12/16/24/32）、圆角、阴影
- 组件库：商品卡（瀑布流双列）、金刚区图标、参数标签 chip、按钮（主/次/禁用）、弹层、空态插画位、搜索框、tab 切换
- Frame 命名与小程序路由一致（见 docs/design/figma-handoff.md），组件 kebab-case
- 每页四态：默认 / 加载 / 空态 / 错误

## 1. 首页（pages/index）
- 顶部：Banner 轮播（2-3 个运营位，图+文案，指示器）
- 金刚区：分类导航（乳胶 / 弹簧 / 棕垫 / 儿童 / 加厚 / 更多…，图标+文字，4-8 个入口）
- 推荐 Feed：双列瀑布流商品卡 —— 主图、商品名（最多 2 行）、核心参数标签 chips（材质/软硬度/厚度/适用人群 中选 2-3 个）、收藏态角标
- 下拉刷新 + 触底加载指示

## 2. 分类页（pages/category）
- 左侧一级分类列表（乳胶/弹簧/棕垫/儿童…）+ 右侧商品网格
- 顶部标签过滤（软硬度：偏软/适中/偏硬；厚度；适用人群）

## 3. 列表页·搜索（pages/goods/list）
- 顶部搜索框（示例词：「席梦思」「护脊」「1.8米」）+ 搜索历史可选
- 分类 chips 横滑过滤
- 双列瀑布流；无结果空态（插画+文案+清除条件按钮）

## 4. 商品详情页（pages/goods/detail）
- 顶部：主图/视频轮播（视频角标）
- 核心参数卡片：材质 / 软硬度 / 厚度 / 适用人群 四项，图标+数值
- 详细图文介绍（富文本占位）
- 底部操作栏：加入选品单（主按钮）+ 已在选品单状态 + 多规格 SKU 选择弹层（尺寸单选）

## 5. 内容 Feed（pages/content/feed）
- tab：最新 / 最热
- 图文卡（封面+标题+阅读数）与视频卡（封面+时长角标+播放icon）混排
- 单列或双列由你定（给出理由）

## 6. 图文详情（pages/content/article）
- 富文本正文（标题/封面/正文），图片懒加载
- 底部「关联商品」横滑卡片组（内容带货），点击进商品详情

## 7. 视频详情（pages/content/video）
- 视频播放器（16:9）+ 全屏切换
- 底部关联商品横滑卡片组

## 8. 选品单列表（pages/wishlist/list）
- 我的选品单卡片：名称（主卧床垫备选/次卧床垫备选）+ 商品数 + 封面缩略图组（最多3张叠放）
- 新建入口（空态：插画+「创建第一个选品单」）
- 重命名 / 删除（长按或右侧菜单）

## 9. 选品单详情（pages/wishlist/detail）
- 单内商品列表（图+名+参数标签+移除）
- 底部/右上：分享按钮
- 被分享打开态（好友视角）：顶部提示「来自 XX 的分享」+ 只读（无编辑入口）

## 10. 分享海报（可选先出概念稿）
- 精美卡片：小程序码 + 选品单名 + 商品缩略 + 品牌位
- 海报为 P1（backlog），概念稿先行即可

## 11. 个人中心（pages/user）
- 未登录态：微信一键登录按钮
- 已登录态：头像昵称 + 我的选品单入口（带数量）+ 内容足迹可选
- tabBar 四页：首页 / 内容 / 选品单 / 我的（图标+选中态）

## 待用户确认项（影响设计，出稿前先问）
1. 商品卡/详情是否展示价格或参考价区间？（PRD 无交易模块，默认不展示，但运营可能要放「到手价」当卖点）
2. 品牌调性：床垫=睡眠/舒适/信任，倾向暖色（米/棕/暖橙）还是冷色（蓝绿/科技感）？或你有参考 App（如躺岛/蓝盒子/网易严选）可直接说
3. 金刚区分类定稿（乳胶/弹簧/棕垫之外还要哪些入口）
