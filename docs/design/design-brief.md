# 床垫选品方案小程序 — 设计任务书（Design Brief）V2.0

> 消费方：用户确认 → CC（Claude Code）按稿实现 → Hermes（pm）对照验收
> 版本：V2.0 / 2026-11-05，需求源：仓库根 `aaa.md`（技术需求规格说明书 V2.0）+ docs/product-specs/PRD-v2.0.md
> 参考图：`jp/` 目录已有一批页面参考图（首页/产品分类列表/产品详情/产品页/我的/方案选择 1-5），可作还原基准或直接采纳

## 0. 画板与全局规格（先做，作为 Design System 页）
- 基准 375 x 812（iPhone），出图 2x
- 设计 token 一份（命名/取值齐全）：色板（primary/成功/警告/危险/中性灰阶 8 级）、字号梯度（大标题 24/标题 20/正文 16/辅助 13/标签 11）、间距梯度（4/8/12/16/24/32）、圆角、阴影
- 全局色：品牌金 `#D4A574`（悬浮选款按钮/强调色，aaa.md §3.1.2）；睡感标签背景 `#FFE4E1`（aaa.md §3.3.2）
- 组件库：产品卡片、参数标签 chip、悬浮选款按钮（56rpx 圆形）、底部已选栏、空态插画位、搜索框、tab 切换、折叠面板
- Frame 命名与小程序路由一致（见 docs/design/figma-handoff.md），组件 kebab-case
- 每页四态：默认 / 加载 / 空态 / 错误

## 1. 首页（pages/index）
- 顶部：Banner 轮播（2-3 个运营位，swiper 自动播放 5s，指示器；jump_type 1~4：无跳转/分类/指定产品/外链）
- 产品分类入口：7 大分类宫格（2 列）：9M 特制床垫 / 花筑手作 / 卷绵时代 / 小斑马 / 特制软床 / 抗菌软床 / 助眠枕头
- 品牌服务板块：横向滚动卡片（服务九部曲 / 学习成长之旅 / 体验之旅）
- 辅助入口：宝顿资讯 / 联系客服
- 全局：右下角「选款」圆形悬浮按钮（品牌金 #D4A574），带已选数量角标（Pinia）

## 2. 产品列表页（pages/product/list）
- 顶部搜索栏（防抖 300ms，历史记录 10 条）
- 左侧分类侧边导航 + 右侧产品列表
- 排序（综合/推荐/新品）+ 视图切换（宫格 2 列 / 列表 1 列）
- 产品卡片：主图/名称/型号/规格/睡感标签/卖点 tags/可选价格；右下角圆形 + 按钮加入选品，已选置灰
- 底部已选栏：已选 N 个 + 缩略图 + 移除 × + OK 按钮

## 3. 产品详情页（pages/product/detail）
- 顶部产品轮播（主视觉+卖点图，lazy-load）
- 产品名称 + Slogan + 规格尺寸 + 睡感标签
- 操作条：[分享] [小程序码] [选款]
- Tab：产品详情（富文本：面料/填充层/支撑结构/工艺）| 实拍图
- 底部：分享按钮 + 选款按钮

## 4. 方案编辑页（pages/scheme/edit）
- 方案标题输入（必填 1-20 字）
- 已选产品横向滚动卡片（× 删除，确认弹窗）+ 添加占位框
- 产品数量 + 详细说明折叠面板（textarea 4 行）
- 底部操作栏：我的方案 / 保存 / 预览分享

## 5. 方案列表页（pages/scheme/list）
- 方案卡片：首图 + 标题 + 产品数量 + 日期
- 长按删除（确认弹窗）；空态：「暂无方案，快去创建吧」+ 去选品按钮

## 6. 方案预览页（pages/scheme/preview）
- 长流式：方案标题（大字号居中）+ 每产品完整海报（主图/名称/规格/睡感/核心参数）
- 底部：返回编辑（仅创建者可见）/ 立即分享
- 被分享打开态（访客）：纯只读，无编辑入口；顶部提示来源

## 7. 个人中心（pages/user）
- 品牌介绍（图文：成立时间/总部/生产规模/门店数/定位文案 + 门店图）
- 招商加盟：「加入我们」按钮（拨打 400 电话，号码后台可配）
- 客服承诺：⚡3分钟响应 / 5分钟出方案 / 8分钟解决售后
- 我的方案入口

## 待用户确认项（影响设计，出稿前先问）
1. 商品卡/详情是否展示价格或参考价区间？（aaa.md 定为后台可配置「是否显示价格」，默认不展示）
2. 「选款」悬浮按钮与底部已选栏的视觉优先级（是否始终悬浮在列表页之上）
3. 产品实拍图是否需要瀑布流双列 vs 单列大图（以 `jp/产品详情页.jpg` 参考图为准）
