# 页面规格（Design Spec）

## 1. 产品定位

面向家装/床垫选购场景的微信小程序：**看品牌 → 逛产品 → 自己拼方案 → 分享给家人**。

核心差异点是「方案选品」——不是普通电商详情流，而是让用户自选产品组合成一份可转发给家人的推荐清单。

## 2. 页面链路

```
首页 / 产品分类列表
   └─ 产品页（按系列/分类）
        └─ 产品详情页
             └─ 选款（FAB）

方案选择1 新建空态 → 方案选择2 选品 → 方案选择3 已选编辑
                        ├─ 保存 → 方案选择4 方案列表
                        └─ 预览分享 → 方案选择5 预览分享 → 立即分享

底部导航：首页 / 产品 / 我的
```

三条主线：

1. **浏览线**：首页 → 产品分类列表 → 产品页 → 产品详情页
2. **选品线**：任意页面「选款」浮动入口 → 选品 → 编辑 → 保存/分享
3. **品牌线**：我的 → 品牌介绍 / 客服服务

## 7. 待确认问题（按阻塞程度排序）

### 阻塞级（不定无法开发）

1. **底部 Tab 两套结构不统一**
   - 首页 / 产品分类列表 / 我的 → `首页 · 产品 · 我的`（三项，`icon/home` `icon/grid` `icon/user`）
   - 产品页 / 产品详情页 → `首页 · 返回`（两项，`icon/home` + `undo-2`）
   - 且后两页**顶部导航左侧也已是返回箭头**，底部「返回」与之功能重复。
   - 需明确：详情类页面到底用「底部 Tab」还是「顶部返回+无 Tab」。

2. **价格信息全流程缺失**
   - 产品页列表卡、产品详情页、分享卡均无价格位。
   - 若是 B 端/线下询价模式需明确说明；否则列表卡与详情页需补价格组件（含促销价/划线价/起售价）。

3. **「我的」页无方案入口**
   - 方案列表（`86:662`）只能从方案编辑页的 `我的方案` 按钮进入。
   - 用户从首页出发，「我的」页无法找到自己保存的方案 —— 关键资产缺入口。

4. **方案编辑页三按钮无主次**
   - `我的方案`(108) / `保存`(92) / `预览分享`(119) 均为 42 高胶囊，两个 yellow 并列。
   - 建议：`保存` 保留主按钮通栏；`预览分享` 降为次按钮；`我的方案` 提到导航栏或文字链。

### 需补充设计

5. **链路断点**（点击后无目标画板）：搜索结果页、品牌介绍页、客服会话页、文章列表页。
6. **缺失状态**：
   - 空态：方案列表为空、搜索无结果、选品未选任何产品
   - 加载态：列表骨架屏、图片加载失败占位
   - 表单态：方案标题为空/超长校验、详细说明展开态、键盘遮挡处理
   - 反馈态：保存成功/失败 toast、删除二次确认、分享失败
7. **产品页排序规则**：综合 / 推荐 / 新品 的具体排序逻辑未定义。
8. **产品页视图切换目标样式**：右上 `list` 图标点击后切换到什么样式，无画板。

### 数据与一致性

9. **占位数据未替换**：
   - 产品页 8 个产品名为临时名（`3D床垫` / `幸福1号` / `幸福2号` / `幸福3号` / `幸福99床垫` / `505压缩卷包床垫` / `323特制版床垫` / `9M 卷绵特制床垫`）
   - 所有规格硬编码为 `1800 × 2000 mm`
   - 方案列表日期硬编码 `2026.11.04`，需定义动态格式（建议 `YYYY.MM.DD`）
   - 方案封面、产品图多处复用同一张图
10. **选品页画板宽 381px**（其他页均 375px），超出 6px，疑为误操作，需核对。
11. **选品页产品卡字号为非整数**（9.88 / 7.6 / 8.36px），是等比缩放的中间结果，实现时需重算为整数。
12. **版本标识条 `V3 · 参考复刻优化版` 共 10 处**混入正式画板，上线前统一移除。

### 可用性

13. **可点面积偏小**：
    - 选品页 `×` 移除按钮 49×12（文字部分）
    - 详情页 `分享` / `小程序码` 图标 24×24 配 11px 文字
    - 产品卡 `查看详情` 58×20
    - `了解更多` 文字热区
    - 建议热区不小于 44×44，或扩大透明热区。
